# Strata

A private place for what you think, watch, read and hear.

Stage 1: sign in or try it out, app lock (PIN and fingerprint), quick cards with a writing timer,
long reflections, thoughts with topics and earlier versions, threads, Flip through, Discarded with
30-day restore, search, export.

- Built with Next.js (exported as static files) and Supabase.
- Setup steps: see [SETUP.md](SETUP.md).
- Database: [supabase/schema.sql](supabase/schema.sql).
